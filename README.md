## Controls ##

"ASWD" to move.  
Q,W to rotate.  
Z,X to zoom.  
H to hide menu.  
Mouse controls are supported.

## Installation ##

1. Open Visual Studio Code and install Python extension.
2. Install PIP on Terminal
`python get-pip.py`
3. Install Pyames
`pip install pygame`
4. Run fftr.py
`python fftr.py`

## Project Structure: ##

- `fftr.py`: root launcher
- `scripts/`: Python game and test modules
- `data/`: CSV game data
- `assets/`: image and audio assets

Run the game from the project root with:

```text
python fftr.py
```
